# Brand assets

Place the official DABZ Printshoppe logo here as `logo.png`, then set
`HAS_LOGO_ASSET = true` in `src/components/brand.tsx`.

The artwork is a dark-background asset — red "DABZ" wordmark with white
"PRINTSHOPPE" beneath a crest — so it is only ever rendered on `bg-ink`
surfaces (the sidebar and the login screen), never on a white card.
